# 管家婆辉煌版ERP · 文员实训网页后台

**在线网站：** https://blueevening.github.io/wyerpmn/

模拟 **广西老街坊商贸有限公司** 的商务文员账号（无财务审核 / 成本结转 / 凭证记账权限）。

## 使用方法

1. 双击打开 `index.html`（Chrome / Edge）
2. 首次进入会显示右下角 **分步教程**，点【下一步】跟着练（共 10 步）
3. 想重看教程：点左侧菜单最底部的【分步教程】按钮
4. 二级页面底部都有【返回列表】/【返回工作台】

## 权限（文员）

| 可以做 | 不可以做 |
|--------|----------|
| 商品/供应商/客户档案增改查、停用 | 财务审核单据 |
| 采购/销售订单：保存草稿、提交审核 | 成本结转、改结转价 |
| 库存查询、预警、台账、流水 | 直接调整库存 |
| 销售/采购退货单：提交待审、模拟仓管确认 | 红冲、收付款核销 |
| 盘点单：录入实盘数、提交待审、模拟仓管确认 | 改报表源数据 |
| 按日期筛选、预览、导出报表（CSV） | |

## 配套练习指令（按顺序做）

1. **建档**：左侧「基础资料 → 商品档案」点【+ 新增商品】，编码打 `SP001`、品名打 `原味花生`、单位打 `包`、分类打 `农副食品`，点【保存】。再切到「供应商资料」点【+ 新增供应商】，编码 `GYS001`、名称 `南宁桂味食品批发部`，点【保存】。
2. **录采购单**：左侧「采购管理 → 采购订单」点【+ 新增采购订单】，选供应商、点【+ 添加行】选「原味花生」数量 100 单价 4.5，点【保存并提交审核】。
3. **录销售单**：左侧「销售管理 → 销售订单」点【+ 新增销售订单】，选「老街坊便利店（建政店）」、点【+ 添加行】选「原味花生」数量 20 单价 6.0，点【保存并提交审核】。
4. **查库存**：左侧「库存管理 → 实时库存」，品名框打 `花生` 点【查询】；再切到「库存预警」看标红的低库存商品。
5. **查流水**：左侧「库存管理 → 出入库流水」，选起止日期，点【查询】核对单据号，点【导出】下载 CSV。
6. **出报表**：左侧「报表中心 → 业务报表」，报表类型选「客户销售明细表」，选近一个月日期，先点【预览】再点【导出Excel】。
7. **做退货（演示）**：左侧「销售管理 → 销售退货」点【+ 新增销售退货单】，「原销售单」下拉选一张已出库单，填退货数量，点【提交待审】；打开这张单，点底部【模拟仓管确认（库存回加）】。
8. **做盘点（演示）**：左侧「库存管理 → 盘点单」点【+ 新增盘点单】，点【+ 添加行】选一个商品，实盘数填一个和账面数不同的数字，点【提交待审】；打开后点【模拟仓管确认（差异入账）】。
9. **进销存汇总**：左侧「报表中心 → 进销存汇总」，选起止日期，点【查询】，再点【导出 CSV】——导出后工作台「实训任务卡 L6」自动打勾。

## 实训任务卡 L1–L6 怎么算完成

- **L1 商品+供应商建档**：商品档案和供应商列表里各至少 1 条
- **L2 采购入库**：系统里有状态为「已入库」的采购单（演示数据自带 2 张）
- **L3 销售出库**：系统里有「已出库」或「部分出库」的销售单（演示数据自带）
- **L4 销售退货**：有状态为「已退货」的退货单（自己录一张并点「模拟仓管确认」）
- **L5 盘点**：盘点单列表里至少有 1 条记录
- **L6 导出进销存汇总**：在「报表中心 → 进销存汇总」点过【导出 CSV】
