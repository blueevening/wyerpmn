# 管家婆辉煌版ERP · 文员实训网页后台

**在线网站：** https://blueevening.github.io/wyerpmn/

模拟 **广西老街坊商贸有限公司** 的商务文员账号（无财务审核 / 成本结转 / 凭证记账权限）。

## 使用方法

1. 双击打开 `index.html`（Chrome / Edge）
2. 首次进入会显示右下角 **分步教程**，点「下一步」跟着做
3. 任意二级页面左上角或按钮区都有 **← 返回** / **返回工作台**

## 权限（文员）

| 可以做 | 不可以做 |
|--------|----------|
| 商品/供应商/客户档案增改查、停用 | 财务审核单据 |
| 采购/销售订单：保存草稿、提交审核 | 成本结转、改结转价 |
| 库存查询、预警、台账、流水 | 直接调整库存 |
| 按日期筛选、预览、导出报表 | 红冲、收付款核销、改报表源数据 |

## 模块

- **工作台**：待办、预警、快捷入口
- **基础资料**：商品 / 供应商 / 客户
- **采购管理**：采购订单、入库单查阅
- **销售管理**：销售订单（草稿/待审核/待出库/部分出库/已出库）
- **库存管理**：实时库存、预警、台账、流水、盘点（只读）
- **报表中心**：库存表、客户销售明细、采购明细 → 导出 CSV（可用 Excel 打开）

## 配套练习指令

1. 打开基础资料 → 商品档案 → 新增：品名「原味花生」，单位「包」，分类「农副食品」
2. 打开库存管理 → 库存台账，查 2026-08-01 ~ 2026-09-10
3. 销售管理 → 新增销售订单草稿：选客户、商品原味花生、数量 50
4. 报表中心 → 客户销售明细表 → 导出
5. 库存管理 → 库存预警，查看低库存列表

## 演示数据

内置食品、日用百货、罐头等 SKU，以及老街坊便利店、邕宁惠民超市等客户，供应商含南宁桂味食品等。点侧栏「重置演示数据」可恢复。
